Inquira

Amazon Product Sales Intelligence

"To build a machine learning system that identifies key factors responsible for poor product sales on Amazon and provides data-driven, explainable insights to improve performance."

Problem Statement

Many businesses launch products but fail to understand why sales remain low. Companies rely on assumptions instead of data to diagnose poor performance.

There is no simple system that:

  • Detects why a product is underperforming
  • Identifies major contributing features (price, discount, rating, sentiment)
  • Provides interpretable SHAP-based explanations
  • Suggests concrete, actionable improvements
  • Analyses product description quality via NLP
Literature Review

Existing approaches include:

  • Simple regression models predicting raw sales numbers
  • Sentiment analysis on product reviews in isolation
  • Price-demand elasticity studies (academic, not actionable)

Limitations of prior work:

  • Predict sales figures but do not explain why a product fails
  • Lack feature-importance interpretation for non-experts
  • Ignore description quality as a sales driver
  • Enterprise BI tools are unaffordable for small sellers

Dataset

Kaggle Amazon Dataset — 1,465 rows × 17 cols. Cleaned, null-dropped, price symbols stripped; target column engineered from rating threshold.

🔧

ML Models

  • Logistic Regression (baseline)
  • Random Forest Classifier (final)
  • Scikit-learn Pipeline (StandardScaler → RF)
  • Serialised to pipeline.pkl via joblib
🧠

SHAP Explainability

  • TreeExplainer on Random Forest
  • Class-1 (Low Selling) SHAP values extracted
  • Top-3 features ranked by |SHAP|
  • Human-readable reasons + fix suggestions
📝

NLP – Description Analyser

  • TextBlob for sentiment polarity
  • Gensim for topic / keyword analysis
  • Auto-computed desc_length feature
  • Flags thin / poor-quality descriptions
🌐

Flask Web App

  • Single-page form: 7 numeric inputs + description
  • Jinja2 templates, custom CSS
  • Returns prediction + reasons + suggestions
